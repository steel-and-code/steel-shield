# Contributing to Steel Shield

Bug reports, fixes and translations are welcome.

- **Report a problem:** open an issue with your Linux distribution and version,
  what you did, what happened, and the output of `steel-shield status`.
- **Send a fix:** fork, make the change, run `make test`, open a pull request.
  The Test workflow must pass.
- **Keep it plain:** messages users see are written in plain English, say what
  happened and what to do next, and never claim protection that is not there.
- **Keep it light:** the scanner runs only while scanning, at the lowest
  priority. Changes that keep something running in the background need a good
  reason.
